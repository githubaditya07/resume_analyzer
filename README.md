# CareerLens AI

CareerLens is a student-focused resume review and career-guidance application. It runs locally with SQLite and an offline, rules-based analysis engine. It does not require PostgreSQL, an AI key, or any external analysis API.

> **Educational use only.** CareerLens provides suggestions, not hiring decisions. Keyword matches are indicative and are not probabilities of employment. A missing resume mention does not mean you lack a skill.

## Run it

Requirements: Node.js 20.9 or later and npm.

```powershell
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000), create an account, and use the Analyze page to paste a resume or upload a text-based PDF, DOCX, or TXT file. On first run, the app generates its Prisma client, creates the local database, seeds the reference role catalog, and creates a private session secret.

No `.env` file is needed for local use. Optional settings are listed in [.env.example](./.env.example). To run a production build locally, use:

```powershell
npm run build
npm start
```

## Local data and privacy

- SQLite data and the generated session secret are stored in `.local-data/`, which is excluded from Git.
- Account passwords are stored as bcrypt hashes.
- Uploaded binary resume files are parsed in the request and are not retained; extracted resume text and reports remain in the local database until deleted.
- Resume analysis runs in this application using local keyword and section-heading rules. Resume text is not sent to an AI service.
- Protect the computer and any backups containing `.local-data/`; anyone with access to those files may access stored information.

## What the offline analysis does

The local engine looks for known skills, common resume section headings, evidence phrases, and selected measurable outcomes. It uses those observations to produce a structured report, reference-role comparisons, skill-gap suggestions, and a learning plan. It does not understand context like a language model, verify claims, guarantee that its keyword list is comprehensive, or assess a person's actual ability. Read the report critically and only add claims you can substantiate.

The reference job catalog is bundled and seeded locally; it is not a live vacancy feed.

## Administrator

Student accounts work immediately after registration. Administrator access is intentionally not created with a default password. To seed an administrator, set `ADMIN_EMAIL` and a unique `ADMIN_PASSWORD` of at least 16 characters in the environment, then run:

```powershell
npm run db:seed
```

Unset those variables after provisioning the account.

## Limitations

- Scanned/image-only PDFs need OCR, which is not included.
- Analysis is keyword- and heading-based, not generated by a large language model.
- The database is local to this installation. It is not a multi-device or multi-instance deployment database.
- No live job feed, application deadlines, salaries, vacancies, placement outcomes, or hiring guarantees are supplied.
- Review the privacy, security, retention, and operational requirements before using real student information in an institutional deployment.
